# ANANT VR Super Platform (अनंत VR सुपर प्लेटफार्म) 🇮🇳

A sovereign 9-in-1 digital super platform & 360° VR spatial metaverse built with React, TypeScript, Tailwind CSS, Google Gemini AI, and sovereign Indian services.

## 🚀 Quick Start
```bash
npm install
npm run dev
```

## ⚡ Vercel Deployment
1. Import this repository into Vercel (https://vercel.com/new).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!
